# Падающие фигуры

Одиночная настольная головоломка для Windows, разработанная как курсовой проект на C# и WPF. Заполняйте горизонтальные строки на поле 10 × 20 и набирайте очки. Игра использует 14 типов фигур и 19 форм с учётом зеркальных вариантов. Каждые 10 очищенных строк повышают текущий уровень до максимального пятого. С уровнем меняются скорость падения, палитра фигур и темп музыки.

## Сборка и запуск

Нужны Windows и .NET SDK 10. Выполните команды из папки с `Tetris.slnx`.

```text
dotnet build Tetris.slnx
dotnet run --project src/Tetris.Desktop/Tetris.Desktop.csproj
```

В главном меню выберите начальный уровень и схему управления, затем нажмите «Начать партию». Пауза включается по `Esc`, по кнопке «Пауза» и при потере окном фокуса. С паузы можно вернуться кнопкой или новым нажатием `Esc`. Кнопка «Звук» управляет музыкой и эффектами.

## Управление

| Действие | «Стрелки · A / D» | «J / ; · K / L» |
|---|---|---|
| Сдвиг влево / вправо | `←` / `→` | `J` / `;` |
| Поворот против / по часовой стрелке | `A` / `D` | `K` / `L` |
| Ускоренное падение при удержании | `↓` | `Space` |
| Пауза и возобновление | `Esc` | `Esc` |

Клавиши привязаны к физическим позициям и работают при русской раскладке. Удержание клавиши сдвига повторяет движение. Поворот выполняется один раз за нажатие.

## Рекорды и оформление

- «Последние 10» показывает последние сохранённые партии, «Топ-5» — лучшие по очкам. При равном счёте выше партия с меньшим временем, приведённым с учётом начального уровня. Игра записывает результаты в `db/recent.json` и `db/top.json`. В сборке вне папки проекта `db` создаётся рядом с приложением.
- Если установлен Python 3, запустите `python switch_theme.py` из корня проекта и выберите **Dark Green** или **Night Archade**. Скрипт заменяет файлы оформления в `src/Tetris.Desktop` и пересобирает решение. Тема применяется при следующем запуске. В репозитории выбрана Dark Green.
